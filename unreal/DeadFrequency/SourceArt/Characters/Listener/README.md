# The Listener: production asset for Unreal Engine 5.8

Original creature for DEAD FREQUENCY. It is a tall, emaciated humanoid (2.27 m to the base of its head) whose
head is a fleshy acoustic horn. Everything here is generated by the project's Blender scripts in
`tools/blender/ue/` (see "Rebuild"), so every stage can be re-run, inspected and changed.

> **Status: checked in Blender, not yet imported into Unreal.** Geometry, UVs, skin weights, textures and the FBX
> round-trip have been checked in Blender (see `Export/validation.json` and `Renders/`). Import into Unreal 5.8,
> material setup and in-engine review happen on the owner's PC when it is connected. Until then this asset is not
> called game-ready.

## Conventions
- **Units:** centimetres (Blender scene unit scale 0.01), Z up. The creature faces -Y in Blender; with the FBX axis
  settings below it imports facing +Y in Unreal, the same as the Unreal mannequin, so the character Blueprint
  rotates the mesh -90 degrees in yaw as usual.
- **Skeleton:** 100 bones. The armature object is named `Armature`, which Unreal's FBX importer drops, so `root` is
  the skeleton root. Names follow the mannequin: `pelvis`, `spine_01..05`, `neck_01..02`, `head`, `clavicle_l`,
  `upperarm_l`, `lowerarm_l`, `hand_l`, `<finger>_metacarpal_l`, `<finger>_01..04_l` (four phalanges: the
  Listener has an extra joint), `thumb_01..03_l`, `thigh_l`, `calf_l`, `foot_l`, `ball_l`. The horn has
  `membrane_throat` and nine strut chains, `membrane_strut_NN_01..03`, for flaring, folding and rippling.
- **Skin weights:** up to 4 influences per vertex, normalised. The body uses bone-heat weights smoothed slightly.
  Each claw is rigid on the last bone of its digit. The membrane is weighted from its own geometry: the throat to
  `head`, then the two nearest struts by angle and the chain bone by depth, so the inner and outer skins move
  together.
- **Materials (slots):** `M_Listener_Skin`, `M_Listener_Claws` (body texture set), `M_Listener_Membrane`.
- **Textures:** `BC` base colour (sRGB). `N` normal map, **DirectX convention** (green flipped), ready for
  Unreal. `ORM` packs AO (R), roughness (G) and metallic (B, all 0); import it as linear (sRGB off, compression
  Masks). `SSS` is the subsurface strength mask (linear) for the Subsurface Profile shading model.
- **Triangulation:** the game meshes are triangulated once, before baking, and exported as those triangles, so
  the normal map's tangent space matches Unreal's (MikkTSpace on the same triangles).

## Animation set (in place, 30 fps)
| Clip | Frames | Loop | Plays at (cm/s) | Use |
|---|---|---|---|---|
| Idle | 120 | yes | 0 | Dormant/watch: breathing, weight shifts, horn pulsing, finger twitches |
| Walk | 30 | yes | 150 | Patrol |
| Stalk | 30 | yes | 200 | Stalk state: low, deliberate, horn forward |
| Run | 18 | yes | 440 | Hunt: bounding, arms pumping, horn folded back |
| Crawl | 36 | yes | 100 | Vents and low spaces, on all fours |
| Listen | 72 | no | 0 | Hears a sound: snaps toward it, flares the horn, clicks, settles |
| Attack | 54 | no | 0 | Rears back, lunges, seizes with both hands, shoves, recovers |
| Drag | 84 | no | 0 | Reaches into a hiding place, seizes, hauls the player out |

Feet are placed with IK, and each locomotion clip's foot speed equals the speed in the table. Played at that
capsule speed the feet do not slide; in Unreal, put Walk, Stalk and Run in a 1D blend space on speed.

## Unreal import (when the PC is connected)
1. **Skeletal mesh:** import `SK_Listener.fbx` with Skeletal Mesh on, a new Skeleton, Import Mesh LODs off,
   Normal Import Method *Import Normals and Tangents*, Create Physics Asset on, Import Uniform Scale 1.0,
   Convert Scene on. Then add LOD1-3 from `SK_Listener_LOD*.fbx` in the LOD settings (Import LOD).
2. **Animations:** import each `A_Listener_*.fbx` with that Skeleton, Animation Length *Exported Time*, frame rate 30.
3. **Physics asset:** match the capsules to `SK_Listener_PhysicsCapsules.json`. The pawn's capsule is 40 cm radius
   and 115 cm half-height, as in `ADFListenerCharacter`.
4. **Materials:**
   - `M_Listener_Skin`: Subsurface Profile shading model with a profile for pale skin (red scatter radius larger
     than green and blue). BaseColor from BC; Roughness from ORM.G; Ambient Occlusion from ORM.R; Normal from N;
     Opacity (subsurface strength) from SSS.
   - `M_Listener_Claws`: Default Lit with the same textures and a little clearcoat.
   - `M_Listener_Membrane`: Subsurface Profile, two-sided off (it is a closed shell), with a stronger scatter
     radius so light shows through the thin membrane.

## Rebuild
```
blender -b --factory-startup --python tools/blender/ue/listener4.py -- <stage>
```
Run the stages in this order: body, head, details, retopo, uv, assemble, bake, textures, rig, anim, lods,
export, validate. The render stages are preview_full, preview_wire, lookdev, rigtest and anim_sheets; run them
under `xvfb-run -a` because EEVEE needs a display. Intermediate files go to `tools/blender/work/ue/listener/`
(git-ignored).
